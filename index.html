JellyC fleet · three levels

Level 1 SERVER. Level 2 SYSTEM (or GROUP for externals). Level 3 is a process inside a system, or a named provider inside a group. Dashed frames are the VPCs: no app host has a public IP. Checked against AWS, the tailnet and the code on 3 Nov 2026.

Solid vs dashed Solid accent arrows are SYSTEM → SYSTEM hops, each with its own API key or ticket, over private DNS or the internal ALB: 1 WenningNo.2 as user · 2 Monitor Hub → Nautilus book · 3 Tolas trigger bots → Trading Monitor, across the peering · 4 Daily Report and Pulse → Nautilus noon book · 5 fleet SSO, Tolas redeems its ticket at Nautilus (Hub, Unified, Trading Monitor and the four reports do the same) · 6 Fund Ops → Nautilus through the ALB · 7 Nautilus pulls the Tolas users.json over SSH. Dashed arrows are a process calling a concrete provider; their color matches the caller. Slate dashed arrows are entry paths. The old “Nautilus → Tolas live orders” hop is gone: no such call exists in the code.
